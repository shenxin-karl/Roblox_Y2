### 解锁价格曲线

- [ ] **验收完成**

---

> 解锁价格 = 向下取整（基础值 + 槽位 ID 的幂值次方 × 倍率）

- 用完整的槽位解锁曲线采样，直接传入 `State.slots` 对应项的 `id`，不使用 UI 索引代替 ID，也不增加偏移。
- 只为现有槽位采样；输入必须是配置闭区间内的整数，框架对小数或范围外输入报错，不夹取或默认补值。
- 结果用于 Inspector 的未解锁槽位价格文本和解锁 Action 的余额校验、扣款；Game 不采样或显示价格。
- 已解锁槽位在 Action 中先阻止重复解锁，Inspector 只显示已解锁状态，不再采样价格。

**配置来源**

[config.json](../Data/config.json) 的 `slotUnlockCurve`：`input` 定义槽位 ID 与合法范围；`formula` 定义基础值、倍率、幂值及结果取整；`editor.display` 定义预览坐标与采样范围。

**实现来源**

[Formulas.ts](../Code/Formulas.ts) 的 `calculateSlotUnlockPrice()`；[Actions.ts](../Code/Actions.ts) 的 `UnlockSlotAction`；[Inspector.ts](../Code/Inspector.ts) 的 `SlotInspector.BuildEditorUI()`。

**当前备注**

待重新验收：展示与扣款已共用同一价格公式，按执行时当前配置结算；价格参数仍为实现占位值，尚未完成数值校准。

### 槽位网格展示

- [ ] **验收完成**

---

- Game 按 `State.slots` 的顺序展示全部槽位，初始 ID 递增，每行六个，共五行。
- 每个槽位按钮宽高相等；左上角单独以小字号显示纯数字 ID，中央按 `State.slots[].unlocked` 显示“未解锁”或“已解锁”，不显示价格或顶部标题。
- 槽位区根面板背景和边框透明；按钮为浅蓝色，中央“未解锁”为灰色，具体颜色由 `Game` 构造函数定义。
- 节点在构造时创建，初始化与后续 UI 更新只刷新 ID 和解锁文字，不重建网格；Inspector 解锁成功后立即同步 Game。
- 在根面板内直接定位各按钮，横纵间距一致，不使用滚动列表；所有按钮及其文字节点位于父面板边界内。展示过程不修改玩法状态。

**配置来源**

槽位列表来自 `State.slots`，行列布局、格子尺寸、按钮间距和 ID 字号由 `Game` 构造函数定义；Game 网格不依赖价格配置。

**实现来源**

[Game.ts](../Code/Game.ts) 的构造函数、`BuildEditorUI()` 和 `UpdateUI()`。

### 点击槽位查看价格

- [ ] **验收完成**

---

- 点击任意槽位按钮，通过框架 `selectInspectable()` 将当前选择设为该位置在 `State.slots` 中的实际 ID，类型为槽位；不会触发购买或修改 State。
- `createProject()` 返回项目 Inspector，按选择 ID 查找当前 State 槽位，显示对应槽位 ID、当前金钱及未解锁时的价格；已解锁时显示状态。
- 切换或重复选择时重建 Inspector 子节点，清除旧回调；同一槽位的价格随配置刷新，复用已有详情节点。
- 未选择、选择类型不匹配或 ID 不属于当前槽位列表时，显示“请选择槽位”，不对不存在的槽位采样。

**配置来源**

[config.json](../Data/config.json) 的 `slotUnlockCurve`；由当前选择定位 `State.slots[].id`，直接以该 ID 采样价格。

**实现来源**

[Game.ts](../Code/Game.ts) 的槽位 `UIButton.OnClick`；[Inspector.ts](../Code/Inspector.ts) 的 `SlotInspector.BuildEditorUI()`；[Main.ts](../Code/Main.ts) 的 `createProject()`。

### 金钱与解锁结算

- [ ] **验收完成**

---

> 初始金钱 = 初始金钱配置值
>
> 解锁后金钱 = 解锁前金钱 − 当前目标槽位解锁价格

- 新运行时从 `initialMoney` 初始化 `State.money`；从 `initialUnlockedSlotCount` 读取初始解锁数量，前序槽位初始已解锁，其余未解锁，不扣金钱。改变初始配置不直接修改当前 State。
- Inspector 的“解锁”按钮只传目标槽位 ID 创建 `UnlockSlotAction`，由 Action 统一判断并结算；按钮禁用态复用 Action 的 `GetBlocker()`。
- 槽位必须存在且未解锁，余额至少等于按当前曲线采样的价格；没有相邻槽位或顺序解锁限制。
- 成功时扣除对应价格并将目标槽位设为已解锁；余额恰好等于价格时可以成功，余额不足、重复解锁或无效 ID 时均不扣款、不改变状态、不消费成功操作。
- 余额不足时“解锁”按钮禁用；成功后按钮显示“已解锁”并禁用，Inspector 刷新余额，Game 对应槽位显示“已解锁”。
- Action payload 仅记录目标 ID，已注册序列化回放工厂，保留操作元数据；回放按当时配置重新计算价格。

**配置来源**

[config.json](../Data/config.json) 的 `initialMoney.value` 提供初始余额，显示在 Config 最外层；`initialUnlockedSlotCount.value` 提供初始解锁数量，`slotUnlockCurve` 提供价格，后两项通过 `editor.folder` 显示在“槽位配置”目录。当前默认余额和价格均为实现默认值，不代表已确认的经济目标。

**实现来源**

[Main.ts](../Code/Main.ts) 的 State 初始化；[State.ts](../Code/State.ts) 的 `money` 和 `slots[].unlocked`；[Actions.ts](../Code/Actions.ts) 的 `UnlockSlotAction.GetBlocker()`、`Apply()` 及注册工厂；[Inspector.ts](../Code/Inspector.ts) 的按钮回调。

**当前备注**

待重新验收：初始金钱移到 Config 最外层，槽位目录保留初始解锁数量和曲线；此前新增的免费初始解锁规则仍待复核。

### 槽位状态保存与恢复

- [ ] **验收完成**

---

- State 初始化金钱和完整槽位列表，各项记录 ID 与解锁标记；Game 读取该列表创建槽位节点。
- `toJSON()` 输出当前金钱、槽位列表和各项 ID 与解锁标记，`loadJSON()` 恢复余额、标记及列表顺序；保存与恢复时复制槽位对象，避免快照与运行状态共享可变对象。
- 新增字段缺省时，金钱使用构造时的初始金钱，槽位标记按该槽位 ID 与构造时初始解锁数量确定；快照中已有的解锁标记原样恢复，不强制覆盖。
- 恢复后刷新 Game 的 ID；点击该位置时使用恢复后的实际 ID 选中槽位，价格仅在 Inspector 从当前曲线采样，不写入 State。
- 状态摘要显示金钱和槽位总数，State 字段提供中文显示名。

**实现来源**

[State.ts](../Code/State.ts) 的 `State.slots`、构造函数、`toJSON()`、`loadJSON()`、`getSummary()` 和 `getFieldDisplayNames()`；[Game.ts](../Code/Game.ts) 的构造函数、`BuildEditorUI()` 和 `UpdateUI()`。

**当前备注**

待重新验收：初始化与缺省解锁标记改为使用初始解锁数量；快照记录的标记仍按原值恢复。
