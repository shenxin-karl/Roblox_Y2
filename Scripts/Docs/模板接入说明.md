# Roblox 地图模板接入

服务端从 `ServerScriptService/Server/Main.server.luau` 启动；玩家创建、Ready 握手、数据保存与同步沿用框架。模板不加载挖矿、训练、转生、光环、武器商店、旧活动、NPC 或礼盒业务。

- 新项目管理员在 `ReplicatedStorage/Scripts/Game/Shared/ProjectConfig.luau` 的 `DeveloperUserIds` 配置，默认空列表；不要沿用其他项目的账号。GM 仅开放本人 `ResetData`、`SaveNow`，不提供客户端界面。
- `Config/StorageConfig.luau` 默认使用 Studio 内存存档，停止试玩即清空。发布前确认云存档名称和测试模式；模板使用新的 `RobloxTemplate_Player` 命名，不读取源项目名称。
- `BuyHandlers`、`ItemHandlers`、`RewardHandlers` 是空的项目扩展入口，统一由服务端注册。没有购买处理器的商品不会通过 Provider 开放；支付回执仅由框架 `FS.ShopService` 接管。
- `SMiscCompClass`、`SAnalyticsCompClass`、`SPurchaseReceiptService` 保留为项目扩展骨架，不预设玩法、漏斗或购买提示。通用统计可调用 `FS.AnalyticsManager`。
- `SGMRecovery`、`SItemToolVisual`、`SRankingServiceClass` 保留。榜单默认不启用；背包字段保留，但未挂载项目背包实现，不自动发放或投影原生 Tool。
- 玩家字段只保留通用货币、音量设置、版本、背包、空引导、购买记录、手持格和首次登录状态。项目协议仅保留音量保存；GM 和本地化提示由框架声明。
- GM 请求由框架管理器统一注册并鉴权，项目通过 `HandleGMCommand` 转发具体命令。本地化提示由框架玩家对象发送、框架通用 UI 翻译显示并响应语言变化；挂载通用 UI 后可用，不依赖项目 UI 子类。

生成配置文件未修改或删除；`ItemConfig`、`GoodsConfig` 继续作为通用道具和商品配置源，其余旧业务配置退出启动流程。正式制作新项目时通过配置工具修改原始 XLSX 并导出，不直接编辑生成文件。

`Game/Shared` 仅保留项目配置、枚举、协议、数据定义与通用函数。枚举、榜单和引导配置是空入口，不预设业务。旧光环、图鉴、商店、转生、福利、武器、挖矿及掉落规则已移除；`InstancePath` 不再保留，固定路径使用 `FX.Loader`，可选节点使用其 Find 或原生查询。

`CMainUICompClass` 保留原生 Tool 装备监听和独立道具说明接入，脚本创建自有 Frame 并复用框架画布。`CCommonUICompClass` 保留通用浮窗与道具名称翻译，不再包含训练点击、出售界面、幸运倍率和售价提示规则。`CSoundCompClass` 保留声音池扩展入口，不预设音乐、音效或玩法字段监听。这三个项目组件启动时均不自动挂载，按新项目需要显式加载和接入。

奖励框架通过 `Provider:GetCurrencyDataConfig` 查询项目允许的货币字段，默认货币和白名单由项目 Provider 维护；非货币字段仍被拒绝。概率工具仅使用 `IsAffectByBetterItemMultiplier` 标记，不再兼容旧幸运字段。客户端入口不强制屏幕朝向，按 Studio 的项目设置生效。背包开关、容量及玩家字段配置保持原值。
