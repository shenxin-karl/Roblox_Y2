# 方块编辑器项目接入

通用发现、授权和交付流程先读 [外部工具协作](../SKILL.md)；已有上下文时复用。

- 工作区：`../BlockEditorWorkspace`；负责方块模型、预制体及编辑器支持的场景或存储节点工作流。
- 文档入口逻辑名为 `bme.docs.read`，显式传入 `file: "AGENTS.md"`；读取返回的相关 skill。节点、脚本事务、模式与 revision 规则以该修订说明和实际 schema 为准。
- 业务操作前核对目标工作区、模式、当前文档和 revision；文档能读不代表编辑器已启动或工程已打开。按工具要求取得启动、切换、保存和导出授权。
- 模型和节点通过 MCP 编辑，不手写模型 JSON、不直接修改运行数据；复用预制体前核对当前工程中的实际身份。
- `game.Workspace.BlockMeshs`、`game.ReplicatedStorage.Assets.BlockMeshs` 及其子树是方块编辑器专属托管范围；修改这些节点的方块几何、变换、材质、结构或预制体时走本工具，先核对实际节点与源资产。不要将所有 Model/MeshPart 都视为方块编辑器资产，也不将普通手工或 AI 制作模型及 GameKit 生成模型放入该范围；模型放置边界按 [Studio 操作](../../roblox-studio-operations/SKILL.md) 执行。
- 对接 Roblox 场景时先查实际导出能力、目标与回执流程；桌面工具栏有同步按钮不代表 MCP 支持同一能力。缺少 MCP 交付能力时明确报告，不虚构导出调用，不绕过托管规则手工重建节点。
- 分别说明模型已修改、已保存、已导出和 Studio 已接收的状态；只读查询实际 Studio 目标子树，不将编辑器预览或本地模型当作场景已更新的证据。
