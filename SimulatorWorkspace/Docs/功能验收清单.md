## 槽位解锁

---

<br>

### 解锁价格曲线

- [x] **验收完成**

---

解锁价格 = `config: 槽位解锁曲线(槽位实际 ID)`。只有槽位存在且未解锁才算价，不用列表位置。当前曲线把 ID × 100 向下取整；ID 不在 1～36 时直接报错，不取最近的值。显示、余额检查和扣款都用这条曲线，价格不存档。

<br>

### 金钱与解锁结算

- [x] **验收完成**

---

1. 新游戏从 0 金币开始，创建 36 个槽位。按 `config: 初始解锁槽位数` 免费解锁列表前几格，目前是 ID 1～5；不算价、不扣款。改配置不会重置正在运行的状态。
2. 购买时先确认目标存在且未解锁，再按实际 ID 算价。不要求相邻槽位已解锁。钱不够就停，余额刚好够也可以买。
3. 扣款后只解锁目标槽位，不生成武器。检查失败不改状态，也不记成功操作。

<br>

### 自动解锁开关与购买顺序

- [x] **验收完成**

---

1. 开关默认关闭，重复设置不生效。开启时立即尝试；构建游戏界面、上线和每个在线秒也会检查，自动解锁排在自动买倍率之后。
2. 每次找列表中第一个锁定槽位，按手动解锁规则算价、扣款。买到后再找下一格，买不起就停，不跳过这一格。
3. 每次解锁单独记录，不加入取剑队列。在线时能花本秒刚到账的金币，上线时能花刚结算的离线金币。关闭开关不影响手动解锁。

## 矿石刷新与取矿

---

<br>

### 整批刷新与变异抽取

- [x] **验收完成**

---

1. 新游戏的刷新计时从 −1 开始。首次构建游戏界面时生成一批矿石，刷新计时归零，并把取矿冷却设为就绪。
2. 每个在线秒先结算金币和取矿冷却，再把刷新计时加 1。计时达到 `config: 矿石整批刷新间隔（秒）` 就换掉整批矿石并归零，不补刷多批。离线和空闲不累加计时；日程上线时会立即换一批，但不调整取矿冷却。
3. 新矿从 1 重新编号。每块独立抽一次变异：各档权重按「衰减系数 ^（变异 ID − 首档 ID）」计算，再除以总权重得到概率。矿石 ID 不参与抽取，改配置只影响下一批。

**配置来源**

- 每批数量：`config: 每批矿石数量`
- 变异权重：`config: 矿石变异概率曲线`

<br>

### 取矿冷却与原料幸运

- [x] **验收完成**

---

1. 冷却每个在线秒加 1，加满 `config: 打造取矿冷却（秒）` 后不再累加。冷却就绪不会自动打造，还需要有请求。
2. 开打前先查冷却，再查剩余矿石、熔炼等级、人物幸运和原料抽取权重。条件不满足就停，不耗矿，也不抽随机数。
3. 从剩余矿石里取变异 ID 最大的一块；同变异时取矿石 ID 最小的。矿石决定成品的变异，不决定原料幸运。
4. 一轮锻造结束后移除这块矿石，冷却归零。即使武器消失也一样。

<br>

### 熔炼幸运范围与抽取权重

- [x] **验收完成**

---

1. 用当前熔炼等级加 −2、−1、0、+1、+2，得到五档原料幸运。低于 1 的结果改成 1，但不合并档位、不改各档权重；也没有幸运上限。
2. 每档权重 = `config: 熔炼原料幸运抽取权重（临时数值）(幸运偏移 + 2)`。五档输入是 0～4，不用熔炼等级查权重。采样不取整，越界报错；每档权重须非负且有限，总权重须为正且有限。
3. 锻造开始时，取一个 [0, 1) 的随机数乘总权重，按档扣掉权重。第一次扣到负数就选该档；刚好扣到 0 继续下一档。若没有命中，用最后一档。
4. 本轮每锤都用这次抽出的原料幸运。人物幸运另外参与单锤判断，改权重不影响已有武器。

## 锻造与槽位置换

---

<br>

### 单锤概率与出炉结果

- [x] **验收完成**

---

1. 本轮先锁定人物幸运和原料幸运。起始品质取「1」和「人物幸运 − 4」中较大者；目标品质是「人物幸运 + 请求偏移」。
2. 每锤用「当前品质 − 人物幸运 + 4」查代码内的基础成功、不变、消失概率。当前品质低于人物幸运时不修正；否则按下方规则调整成功率。
3. 每锤抽一个新随机数，按成功 → 不变 → 破损 → 消失的累计概率判断。成功就加 1 品质，到目标即结束；不变就继续；破损按当前品质出炉；消失则没有成品。没有锤数上限或保底。
4. 整轮在一个 Action 内完成，不扣金币，也不逐锤推进时间。成品继承矿石变异，记录两种幸运和结束品质，从等级 1 开始，ID 是现存武器最大 ID 加 1。最近结果记录矿石、幸运、品质、锤数、结果及成品和入槽 ID；消失时清空当前展示武器 ID。

概率修正（系数写在代码里）：

- 幸运差 = 原料幸运 − 人物幸运，限制在 −10～+10。
- 幸运差为正：基础成功率 ×（1 + 0.2 × 幸运差），最多占用扣掉不变和消失概率后的空间。
- 幸运差为零或负：基础成功率 ×（1 + 0.05 × 幸运差）。
- 不变和消失概率不随幸运差变化，100% 减去这两项和成功概率后就是破损概率。

<br>

### 目标选择与置换重试队列

- [x] **验收完成**

---

1. 单槽置换、批量置换和空槽取剑共用一条队列。槽位已解锁且没排队，就把「槽位 ID + 目标偏移」加到队尾，不用等冷却。偏移只能是 +1～+4，改全局目标不影响已入队请求。
2. 入队后会尝试一次队首；每个在线秒也会在自动买倍率、自动解锁之后尝试一次。只处理队首。每次都重新读人物幸运和熔炼等级，但沿用请求里保存的偏移。
3. 先检查队首的槽位、目标偏移、取矿冷却、矿石和幸运条件。检查不通过就不开打：不扣矿、不重置冷却，任务留在队首，不跳过它处理下一项。
4. 条件通过后先打完这一轮，再扣一块矿石、把冷却归零，最后处理成品：
   - **没出成品**：没有新剑，任务留在队首等下一次尝试。
   - **出了成品但没装上**：有旧剑时，新剑品质必须严格更高，不比较等级、变异或收益。品质没超过旧剑，新剑留库存，任务留在队首，不升级旧剑。
   - **新剑装进槽位**：没有可用旧剑时，有成品就装；有旧剑时，换下的旧剑直接移除。破损出炉只要装上也算成功。
5. 装上新剑后才出队，并立即尝试一次一键升级。金币不够就跳过，不补试。锻造结算和成功升级分别记一笔。

<br>

### 推荐置换与批量入口

- [x] **验收完成**

---

1. 只推荐已解锁的槽位。空槽直接推荐；有武器时，品质不高于玩家锻造等级才推荐。找不到武器的失效引用不算空槽。
2. 单槽置换先判断是否推荐。仍推荐但已经排队时，快捷键不重复入队，但仍会尝试队首一次。
3. 批量置换按槽位在列表里的顺序入队，跳过已排队项，最后只尝试一次队首。重试不会重新判断推荐状态，也不会自动加入其他推荐槽位。

<br>

### 武器等级与一键升级

- [x] **验收完成**

---

1. 一键操作先看槽位：锁定时只解锁，没有武器引用时先排队取剑，有武器时才升级。武器引用失效不算空槽。
2. 每升一级的费用 = `config: 武器升级曲线.升一级费用(该级升级前的武器等级)`。从当前等级开始逐级查价并累计。再升一级会超出余额或等级上限就停；刚好够也可以买。当前曲线接受 1 级及以上整数，没有最高等级。
3. 能升几级就一次扣总价，再加等级；一级都升不起就不改状态。只改等级，不改品质、变异或幸运。之后计算收益时，武器等级倍率 = `config: 武器升级曲线.等级倍率(升级后的武器等级)`，当前是「0.5 + 等级 × 0.5」，不取整。

例：当前每级费用是「升级前等级 × 25」向下取整。2 级有 130 金币时，前两级共 125，下一次还要 100，所以最终升到 4 级、剩 5 金币。详情面板也用同一套算法。

### 升级购买与幸运效果

- [ ] **验收完成**

---

**当前备注**：待重新验收：新增逐轮购买顺序和等级上限；熔炼等级现在决定五档原料幸运的中心。

1. 先检查本次请求的升级项是否存在、当前等级是否是曲线范围内的整数，以及下一等级是否超出上限。当前三项都是 1～32 级，到 32 级就拒绝，不再检查轮次或算价。
2. 再找三项升级中的最低等级。同是最低级时，按「收益倍率 → 武器锻造 → 熔炼幸运」选第一项；如果本次请求的不是这一项，就拒绝，不算价。

三项费用都按升级前的等级采样，例如 2 级升 3 级传入 2：

- 收益倍率升级费用 = `config: 玩家收益倍率升级（临时数值）.升一级费用(当前收益等级)`
- 武器锻造升级费用 = `config: 武器锻造升级价格（临时数值）.升一级费用(当前锻造等级)`
- 熔炼幸运升级费用 = `config: 熔炼幸运升级价格（临时数值）.升一级费用(当前熔炼等级)`

当前三条费用曲线都把「100 × 当前等级²」向下取整。

## 基地金币收益与日程

### 在线金币收益

- [ ] **验收完成**

---

**当前备注**：待重新验收：品质曲线有输入上限；本秒自动购买、解锁和置换会影响后续余额与收益。

1. 只计算已解锁槽位里实际存在的武器。空槽、找不到武器的引用和库存武器都没收益。
2. 每把剑用自身品质查基础秒收益，再乘武器等级、变异和玩家收益等级对应的倍率。两种幸运不直接参与。
3. 把所有有效武器的收益相加，再乘当前已购档位的付费倍率，一次加到金币余额。界面显示两位小数，不会把实际余额取整。
4. 本秒先加金币，再推进冷却和矿石刷新，最后按「自动买倍率 → 自动解锁 → 尝试队首置换」处理。后来买到的档位或换上的武器不补算本秒收益。

**收益计算用到的曲线**

- 基础秒收益 = `config: 武器品质基础秒收益（临时数值）(武器品质)`。当前是 1.2 的品质次方，输入整数 1～36，越界报错。
- 武器等级倍率 = `config: 武器升级曲线.等级倍率(当前武器等级)`，不取整。
- 变异倍率 = `config: 武器变异收益倍率（暂为1）(实际变异 ID)`。输入 1～6，当前各档都是 1。
- 玩家收益倍率 = `config: 玩家收益倍率升级（临时数值）.玩家收益倍率(当前收益等级)`。当前是「0.9 + 收益等级 × 0.1」，不取整。
- 最终金币倍率 = `config: 付费倍率逐档购买（钻石方案暂定数值）.最终金币倍率(当前已购档位)`。当前是 2 的已购档位次方，档位 1～11，不连乘历史档位。

### 上线与离线收益结算

- [ ] **验收完成**

---

**当前备注**：待重新验收：上线流程增加了自动解锁。

1. 第一个在线秒之前，框架发出上线通知。首次传离线时长 0；之后传上一场的配置离线时长，跨日也不加空闲时间。

## 钻石与付费金币倍率

---

<br>

### 初始资源与每日赠送

- [ ] **验收完成**

---

1. 新游戏直接设初始钻石和默认档位，不先发奖再扣款。恢复快照时用保存值，不补初始档位。
2. 构建游戏界面和每次上线都会尝试赠钻。没有日程上下文时，界面构建按代码固定的首日处理；关闭日程后不会按现实日期补发。
3. 传入的模拟日是正整数且大于最近领奖日，才加一份当日钻石并更新领奖日。不补跳过的天数，不乘金币倍率。之后的自动购买可能马上花掉部分钻石。

**配置来源**

- 新游戏的钻石余额：`config: 初始钻石（新手35钻已用于默认2倍）`
- 新游戏的已购档位：`config: 新手默认已购倍率档位`
- 每次赠送的数量：`config: 每日赠送钻石`

<br>

### 逐档购买与倍率作用

- [ ] **验收完成**

---

1. 当前档位必须是合法整数。满档直接停，否则购买价格 = `config: 付费倍率逐档购买（钻石方案暂定数值）.本档钻石价格(下一档档位)`。当前价格就是对应档位的参数值，不取整。
2. 钻石至少够下一档价格才扣款，并升一档。余额不足就不改状态。
3. 买到后，最终金币倍率 = `config: 付费倍率逐档购买（钻石方案暂定数值）.最终金币倍率(新买到的档位)`，替换原倍率。倍率只作用于在线和离线金币，不改矿石、幸运、钻石或价格。界面由当前档位算出倍率序列，不读取交易历史。

例：从第 1 档买到第 2 档时，扣第 2 档的 48 钻，倍率由 2 倍改成 4 倍，不叠乘。当前第 11 档就是最高档。

<br>

## 状态保存与恢复

## 异常提醒

---

- **队首可能一直阻塞**：队首槽位无效、锁定，或已保存的目标无法超过旧剑品质时，后面的任务会继续等。改全局目标不会改旧请求，目前也没有取消入口。没装上的成品留在库存，但没有整理、出售或独立放入入口。
- **重设日程可能影响赠钻**：框架从新日程的首日开始，游戏仍保留最近领奖日；旧值可能挡住新日程早期的赠送。
- **部分操作没有独立入口**：代码保留独立打造、主动放入和单级升级，但当前界面没有对应按钮；主动放入允许同品质或低品质替换，不是当前置换队列的规则。
- **旧数据兼容有限**：旧版 `autoForgeSword` 操作已无回放注册；恢复也不补缺失的主要列表。
- **显示和收益不是同一条规则**：矿石 UI 从「变异0」编号，内部 ID 从 1 开始。置换只比较品质，不保证换上以后金币收益更高。
