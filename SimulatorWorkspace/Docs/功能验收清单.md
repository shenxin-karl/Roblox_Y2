## 槽位解锁

---

<br>

### 解锁价格曲线

- [x] **验收完成**

---

解锁槽位花金币，价格由槽位自己的 ID 决定，不由它在列表中的位置决定。

1. 购买时先确认槽位存在且尚未解锁，再计算价格。
2. 解锁价格 = `config: 槽位解锁曲线(槽位实际 ID)`。当前公式为「槽位 ID × 100」，结果向下取整。
3. 详情面板显示的价格、购买前的余额检查和实际扣款使用同一条曲线。价格不保存到存档，每次按当前配置重新计算。

曲线只接受 1～36 的整数 ID。超出范围会报错，不会改用最近一个合法 ID 的价格。

<br>

### 金钱与解锁结算

- [x] **验收完成**

---

1. **新游戏创建槽位**：金币从 0 开始，创建 ID 1～36 的槽位。按 `config: 初始解锁槽位数` 免费解锁列表前几格；当前是前 5 格。所有槽位起初都没有武器。
2. **检查购买条件**：目标槽位必须存在且尚未解锁。不要求相邻槽位已解锁，也不要求先买编号较小的槽位。
3. **检查金币并扣款**：按目标槽位 ID 算价。金币不足时不扣款、不解锁；金币刚好够也可以买。
4. **完成解锁**：扣除金币，只把目标槽位改为已解锁，不生成武器、不自动安排打造。成功解锁会记录为一次操作。

免费解锁只在创建新游戏时执行。修改初始解锁数量不会重新分配正在运行的槽位。

<br>

### 自动解锁开关与购买顺序

- [x] **验收完成**

---

自动解锁默认关闭。开启后，系统会用金币按列表顺序购买未解锁槽位。

1. **触发检查**：开启开关时立即检查。构建游戏界面、每次上线和每个在线秒也会检查；这些流程中，自动解锁都排在自动购买付费倍率之后。
2. **找到下一格**：取列表中第一个尚未解锁的槽位，按手动购买的规则算价、检查余额并扣款。
3. **继续或停止**：买到后继续找下一格。金币不足或购买失败就停止本次处理，不跳过这一格；全部解锁后也停止。只要开关仍开启，之后触发检查时还会再试。
4. **购买结果**：每格单独扣款、单独记录。新解锁的槽位保持为空，不自动加入取剑队列。

自动解锁可以花本秒刚到账的在线金币，也可以花本次上线刚发的离线金币。关闭开关只停止自动购买，不影响手动解锁；重复设置同一开关值不会改变状态。

---

### 槽位网格展示

- [ ] **验收完成**

---

**当前备注**：待重新验收：已解锁的空槽也会显示推荐高亮。

1. **排列槽位**：正常新游戏显示 36 格，九列四行，不滚动。每格左上角显示槽位实际 ID；刷新时按槽位列表顺序更新已有格子。
2. **显示内容**：

   - 已解锁，但没有找到对应武器：显示「空槽位」。

顶部显示总秒收益、付费倍率、钻石、矿石及玩家升级入口。槽位格子不显示解锁价或原料幸运。普通界面刷新只更新显示，不发放收益或执行购买。

### 点击槽位查看价格

- [x] **验收完成**

---

1. **选中槽位**：点击格子后，界面记住它的实际 ID，并更新详情面板。选择本身不扣资源、不修改玩法状态，也不写入存档。
2. **显示详情**：
   - 没有选中有效槽位：显示「请选择槽位」。
   - 槽位未解锁：显示槽位 ID、解锁价格和金币余额。
   - 槽位已解锁：显示金币余额，以及「空槽位」或武器的品质、等级。
3. **显示升级预估**：有武器且允许升级时，显示当前金币最多能升几级、总共花多少金币。一级都升不起时不显示这项预估。
4. **关联快捷键**：W 对选中槽位执行解锁、排队取剑或武器升级；R 对选中槽位尝试置换。没有选中槽位时，两者都不执行。

切换选择、重建详情面板时，会清除旧节点和旧刷新回调。之后的普通刷新复用现有节点。

## 矿石刷新与取矿

---

<br>

### 整批刷新与变异抽取

- [x] **验收完成**

---

1. **首次生成**：新游戏用刷新计时 −1 表示尚未生成矿石。首次构建游戏界面时生成一批矿石，把刷新计时归零，并让取矿冷却立即就绪。
2. **在线定时刷新**：每个在线秒先发金币、推进取矿冷却，再给矿石刷新计时加 1。达到刷新间隔时，移除当前剩余矿石并生成新的一批，计时归零；一次检查只刷新一批。
3. **上线刷新**：日程每次发出上线通知时，也会立即更换整批矿石并把刷新计时归零，但不会重置取矿冷却。离线和空闲时间不推进这两个计时。
4. **生成矿石变异**：每一批的矿石 ID 都从 1 重新编号，每块矿独立抽取变异。矿石 ID 不参与变异抽取；修改数量或变异配置只影响后续生成的矿石。

变异抽取使用配置中的几何衰减分布：变异 ID 从 1 开始，每档权重 = 衰减系数 ^（变异 ID − 1），每档概率 = 该档权重 ÷ 所有档位权重之和。

**配置来源**

- 在线刷新间隔：`config: 矿石整批刷新间隔（秒）`
- 每批生成数量：`config: 每批矿石数量`
- 变异档数与衰减系数：`config: 矿石变异概率曲线`

<br>

### 取矿冷却与原料幸运

- [ ] **验收完成**

---

**当前备注**：待重新验收：开打前直接检查锻造等级。

取矿冷却限制的是两轮打造之间的间隔，不是排队等待时间。首次进入新游戏时冷却就绪；之后每完成一轮打造，都要重新等待。

1. **检查能否开打**：置换请求先检查目标槽位存在、已解锁，目标偏移是 +1～+4。随后检查取矿冷却、剩余矿石、熔炼与锻造等级，以及原料幸运抽取权重。
2. **条件不满足**：本次不打造、不耗矿、不抽随机数，也不重置冷却。置换请求继续留在队首。
3. **选择矿石和原料幸运**：从剩余矿石里选变异 ID 最大的一块；变异相同时选矿石 ID 最小的一块。矿石决定成品变异，原料幸运则按当前熔炼等级单独抽取。
4. **完成一轮打造**：移除选中的矿石，把取矿冷却计时归零。无论达到目标、破损出炉，还是武器消失，都消耗这一块矿。
5. **等待下一轮**：只累计在线秒数，当前需要等 30 秒。等满后，有置换请求就自动尝试队首；没有请求就不取矿。离线不会缩短这段等待。

熔炼等级和锻造等级都必须是正整数。抽取权重必须为非负有限数，且总权重为正有限数。

**配置来源**

- 两轮打造的间隔：`config: 打造取矿冷却（秒）`

<br>

### 熔炼幸运范围与抽取权重

- [x] **验收完成**

---

每轮打造只抽一次原料幸运，整轮所有锤击都使用这个结果。

1. **确定五档幸运**：以当前熔炼等级为中心，分别加 −2、−1、0、+1、+2。低于 1 的结果改成 1，不另设幸运上限。
2. **读取各档权重**：每档权重 = `config: 熔炼原料幸运抽取权重（临时数值）(幸运偏移 + 2)`。五档依次传入 0、1、2、3、4，不是传入熔炼等级。曲线结果不取整，输入越界会报错。
3. **按权重抽一档**：随机取一个大于等于 0、小于 1 的数，乘以总权重，再按五档顺序依次减去权重。第一次减到负数时选中该档；刚好为 0 时继续下一档。若遍历后仍未命中，使用最后一档。
4. **保存抽取结果**：本轮不重新抽幸运。之后修改权重或提升熔炼等级，不会改动已造好武器保存的原料幸运。

示意：熔炼等级为 1 时，五档幸运是 1、1、1、2、3。前三档虽然幸运值相同，仍各自保留权重，不合并档位。

## 锻造与槽位置换

---

<br>

### 单锤概率与出炉结果

- [x] **验收完成**

---

**当前备注**：验收结论待确认。原文已勾选，同时留有“待重新验收：单锤公式中的 P 改为直接取当前锻造等级，概率算法不变。”的备注。本次仅优化表述，保留原勾选与该备注信息。

一轮打造会连续敲击，直到达到目标品质、破损出炉或消失。整轮在一次操作中完成，不逐锤推进模拟时间，也不扣金币；矿石消耗和冷却按上一节结算。

1. **确定本轮参数**：记本轮开始时的锻造等级为 P，使用本轮抽到的原料幸运。起始品质 = 1 与「P − 4」中的较大值；目标品质 = P + 本次请求保存的目标偏移。
2. **计算这一锤的概率**：用「当前品质 − P + 4」选择代码内的基础概率。当前品质低于 P 时直接使用基础概率；达到 P 后，再按下方幸运差公式修正。
3. **抽取这一锤的结果**：每锤抽一个新的随机数，按「成功 → 不变 → 破损 → 消失」的累计概率判断。
   - 成功：品质加 1；达到目标就出炉，否则继续下一锤。
   - 不变：品质不变，继续下一锤。
   - 破损：立即停止，按当前品质生成武器，可能低于目标品质。
   - 消失：立即停止，不生成武器。
4. **生成和记录结果**：有成品时，从武器等级 1 开始，继承矿石变异，保存原料幸运、本轮 P 和结束品质。武器 ID 取现存最大 ID 加 1；没有现存武器时从 1 开始。
5. **更新最近打造记录**：保存消耗的矿石、锤数、出炉结果、成品 ID 和实际入槽 ID。消失时没有成品 ID，并清空当前展示武器 ID。

没有锤数上限，也没有保证出成品的保底。

基础概率是代码固定值，不来自配置：

| 当前品质相对 P 的差值 | 成功 | 不变 | 消失 |
| --- | --- | --- | --- |
| −4 | 94% | 5% | 0% |
| −3 | 93% | 5% | 0% |
| −2 | 91% | 5% | 0% |
| −1 | 88% | 5% | 0% |
| 0 | 70% | 5% | 3% |
| +1 | 50% | 15% | 5% |
| +2 | 30% | 25% | 10% |
| +3 | 10% | 40% | 15% |

当前品质达到 P 后，按以下顺序修正，系数同样写在代码里：

- 幸运差 = 原料幸运 − P，低于 −10 按 −10，高于 +10 按 +10。
- 幸运差大于 0：成功概率 = 基础成功概率 ×（1 + 0.2 × 幸运差），但最多为「100% − 不变概率 − 消失概率」。
- 幸运差小于或等于 0：成功概率 = 基础成功概率 ×（1 + 0.05 × 幸运差）。
- 不变和消失概率保持不变。破损概率 = 100% − 成功概率 − 不变概率 − 消失概率。

### 目标选择与置换重试队列

- [x] **验收完成**

---

**当前备注**：验收结论待确认。原文已勾选，同时留有“待重新验收：队首重试时用当前锻造等级算目标品质。”的备注。本次仅优化表述，保留原勾选与该备注信息。

置换不是直接换一把库存武器，而是先消耗矿石打造新剑，再判断是否装进目标槽位。排队本身不耗矿、不花金币。

1. **保存目标并入队**：单槽置换、批量置换和空槽取剑共用一条队列。目标槽位必须已解锁且尚未排队；符合条件后加入队尾，并保存当时选定的 +1～+4 偏移。全局目标初始为 +1，之后修改它只影响新请求。
2. **尝试队首**：入队后立即尝试排在最前面的请求，之后每个在线秒再尝试一次，顺序在自动购买付费倍率、自动解锁之后。冷却未结束、没有矿石或其他开打条件不满足时，本次停止，不耗矿，也不跳过队首。
3. **按当前等级打造**：目标品质 = 本轮开始时的锻造等级 + 请求保存的偏移；原料幸运按本轮开始时的熔炼等级抽取。因此，排队后升级锻造等级会提高后续尝试的目标品质，但不会改变请求保存的偏移。
4. **判断是否装上**：只要完成了打造，就消耗一块矿并重新开始冷却，再按以下分支处理：
   - 没有成品：旧剑不动，请求留在队首，等冷却结束后重试。
   - 有成品，但品质不高于旧剑：新剑留在库存，旧剑不动，请求留在队首重试。比较时不看武器等级、变异或金币收益。
   - 有成品，且槽位没有可找到的旧剑，或新品质更高：装上新剑；有旧剑时直接删除旧剑。破损出炉的剑只要满足这个条件，也能装上。
5. **成功后出队并升级**：装上新剑后移除这条请求，立即尝试一次武器一键升级。能升级就扣金币，升到当前余额可负担的等级；不能升级就跳过，不为这次升级另行重试。打造与成功升级分别记录。

每次调用只处理一次队首，不在成功后立即连续打造下一项。未成功的队首会挡住后面的请求；当前没有取消队列的界面入口。

<br>

### 推荐置换与批量入口

- [x] **验收完成**

---

1. **判断是否推荐**：只检查已解锁槽位。
   - 没有记录武器 ID 的空槽：推荐。
   - 有可找到的武器，且品质不高于当前锻造等级：推荐。
   - 武器品质更高：不推荐。
   - 记录了武器 ID，却找不到对应武器：不当作正常空槽，不推荐。
2. **单槽置换**：只有推荐槽位才能从单槽入口发起置换。未排队时加入队尾，再尝试队首；已经排队时不会重复加入，但 R 快捷键仍会尝试一次队首，不一定处理当前选中的槽位。
3. **批量置换**：按槽位列表顺序，把推荐且未排队的槽位加入队尾，最后只尝试一次队首。
4. **后续重试**：已排队请求重试时，不重新检查是否仍被推荐。系统也不会仅因其他槽位变成推荐状态，就自动把它们加入队列。

推荐表示符合入队条件，不表示取矿冷却已结束，也不保证新剑的金币收益更高。

<br>

### 武器等级与一键升级

- [x] **验收完成**

---

1. **先判断 W 或一键升级入口要做什么**：
   - 槽位未解锁：只尝试花金币解锁，本次不继续取剑。
   - 槽位已解锁且没有武器 ID：加入取剑队列，随后尝试队首；装上武器后再尝试升级。
   - 槽位已解锁且有武器 ID：尝试升级该武器。若 ID 对应的武器不存在，停止，不改走取剑流程。
2. **检查是否能升级**：武器必须存在，等级必须是曲线范围内的整数，且允许再升一级。金币连一级都不够时，不扣款、不改等级。
3. **算最多能升几级**：从当前等级开始，逐级计算费用并累加。再买一级会超过余额或配置等级上限时停止；余额刚好够也可以买。当前配置只设最低 1 级，没有最高等级。
4. **一次结算**：扣除累计费用，增加对应等级数。只改变武器等级，不改变品质、变异或原料幸运。

每一级的费用 = `config: 武器升级曲线.升一级费用(这一级升级前的武器等级)`。当前公式为「升级前等级 × 25」，结果向下取整。

升级后的收益使用武器等级倍率 = `config: 武器升级曲线.等级倍率(升级后的武器等级)`。当前公式为「0.5 + 武器等级 × 0.5」，不取整。

算例（按当前配置）：武器 2 级、余额 130 金币，升到 3 级花 50，升到 4 级再花 75。两次共 125；下一次还要 100，买不起。因此一次升到 4 级，剩 5 金币。详情面板使用同一套计算。

## 玩家升级

---

<br>

### 升级购买与幸运效果

- [x] **验收完成**

---

4. **应用升级效果**：

### 在线金币收益

- [x] **验收完成**

---

**当前备注**：验收结论待确认。原文已勾选，同时留有“待重新验收：品质曲线有输入上限；本秒自动购买、解锁和置换会影响后续余额与收益。”的备注。本次仅优化表述，保留原勾选与该备注信息。

每个在线秒结算一次金币。玩家收益升级倍率和钻石购买的付费倍率都会计入，两者相乘，不互相替代。

1. **找到产金币的武器**：只计算已解锁槽位里能找到的武器。未解锁槽位、空槽、失效的武器 ID 和未入槽的库存武器都不产金币。
2. **计算每把武器的收益**：单把武器秒收益（未乘付费倍率）= 品质基础秒收益 × 武器等级倍率 × 变异倍率 × 玩家收益升级倍率。不直接读取锻造等级或原料幸运。
3. **乘付费倍率并到账**：本秒到账金币 = 所有有效武器的上述收益之和 × 当前已购付费倍率。把结果一次加入金币余额，不取整；界面显示两位小数不影响实际余额。
4. **再处理本秒其他变化**：金币到账后，推进取矿冷却、检查矿石刷新，再依次尝试自动购买付费倍率、自动解锁槽位和队首置换。自动解锁和置换后的武器升级可能花掉刚到账的金币。
5. **新倍率和新武器何时生效**：本秒后续流程买到的付费倍率、换上的新武器或升高的武器等级，影响之后的收益，不重新结算已经发完的这一秒。

示意：武器收益汇总后是 100 金币/秒，当前付费倍率为 4 倍，本秒就加 400 金币；若随后自动解锁花掉 300，余额实际只净增加 100。

计算各项时，按以下输入读取配置：

- 品质基础秒收益 = `config: 武器品质基础秒收益（临时数值）(武器品质)`。输入整数 1～36，当前为 1.2 的品质次方，不取整。
- 武器等级倍率 = `config: 武器升级曲线.等级倍率(当前武器等级)`。输入整数 1 及以上，当前为「0.5 + 武器等级 × 0.5」，不取整。
- 变异倍率 = `config: 武器变异收益倍率（暂为1）(实际变异 ID)`。输入整数 1～6，当前各档均为 1。
- 玩家收益升级倍率 = `config: 玩家收益倍率升级（临时数值）.玩家收益倍率(当前收益等级)`。输入整数 1～32，当前为「0.9 + 收益等级 × 0.1」，不取整。
- 当前已购付费倍率 = `config: 付费倍率逐档购买（钻石方案暂定数值）.最终金币倍率(当前已购档位)`。输入整数 1～11，当前为 2 的档位次方，不连乘以前买过的档位。

这些曲线遇到越界输入会报错，不会自动按最高或最低一档计算。

### 上线与离线收益结算

- [x] **验收完成**

---

**当前备注**：验收结论待确认。原文已勾选，同时留有“待重新验收：上线流程增加了自动解锁。”的备注。本次仅优化表述，保留原勾选与该备注信息。

日程在每场第一个在线秒之前触发上线流程。上线不是先买倍率再领收益，而是按下面的顺序执行：

1. **刷新矿石**：换掉剩余矿石，生成新的一批；不调整取矿冷却。
2. **发放离线金币**：用上线这一刻的武器、玩家收益升级倍率和已购付费倍率，按在线收益公式算出秒收益，再乘传入的离线秒数，加入金币余额。
   - 离线秒数必须是正整数；为 0 或无效时跳过发金币，仍继续后面的步骤。
   - 离线期间不逐秒成长，不逐秒购买或打造。只在上线时计算一次，不打折、不取整，也不另设离线时长上限。
3. **赠送当日钻石**：符合每日赠送条件时发钻石；已经领过则跳过，继续下一步。
4. **自动购买付费倍率**：开启自动购买时，用钻石逐档购买，直到钻石不足或满档。此时第 2 步已经结束，新买到的倍率不会重算或补发这次离线金币。关闭开关则跳过购买。
5. **自动解锁槽位**：开启自动解锁时，用当前金币余额按列表顺序买槽位，直到余额不足或全部解锁。余额包含第 2 步刚到账的离线金币，所以这笔钱可能马上被花掉。关闭开关则跳过购买。

买倍率花钻石，解锁槽位花金币。上线流程本身不处理置换队列；随后进入在线秒流程才尝试队首。

示意：上线时已有 2 倍付费倍率，就按 2 倍发这次离线金币。随后即使自动买到 4 倍，也不补发差额；如果自动解锁开启，刚发的金币可以立即用于买槽位。

离线时长来自日程，不是现实中离开游戏的时长：

- 日程首次上线传 0；之后传上一场配置的离线秒数，跨日也不额外加入当天剩余空闲时间。
- 当前日程每天上线两次，每场在线 1800 秒，场后配置离线 7200 秒。模拟 Tick 只累计在线秒数，离线不占用 Tick。
- 离线结算操作本身不保存“这一段是否领过”的标记；正常历史回放由框架按已记录的操作恢复，不重复触发上线回调。

**配置来源**

- 上线次数、在线与离线时长：`__framework.schedule`（框架字段，未配置中文名）

## 异常提醒

---

- **置换队首可能长期不出队**：槽位不存在或被锁定时不会开打；能够开打、但目标品质始终不高于旧剑时，则可能反复消耗矿石却换不上。两种情况都会挡住后面的请求。修改全局目标不改变旧请求，当前也没有取消入口。
- **库存武器没有后续处理入口**：置换时未装上的成品会保留，但界面没有整理、出售或独立放入槽位的入口。
- **重设日程可能暂时领不到钻石**：新日程从第 1 天开始，已有的最近领奖日却不会清零。如果旧领奖日更大，新日程早期的赠送会被跳过。
- **代码操作不等于界面功能**：代码保留独立打造、主动放入武器和只升一级的操作，但界面没有对应按钮。主动放入允许同品质或低品质替换；不能把这条规则套到置换队列上。
- **旧数据不能全部兼容**：旧版 `autoForgeSword` 操作没有回放注册；缺失主要列表的旧快照也不会自动补齐。兼容范围只包括上文明确说明的旧队列和目标偏移处理。
- **变异显示编号与内部 ID 不同**：界面显示“变异0～变异5”，内部 ID 是 1～6，读配置时使用内部 ID。
- **品质更高不等于金币收益更高**：置换只比较品质。新剑从等级 1 开始，变异也可能不同；即使换上并尝试升级，仍不保证最终秒收益高于旧剑。
