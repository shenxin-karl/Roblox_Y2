## 3. 资源关联配置

`initialMoney`（初始金钱）显示在 Config 最外层；`initialUnlockedSlotCount`（初始解锁槽位数）和 `slotUnlockCurve`（槽位解锁曲线）统一显示在“槽位配置”目录。

### 初始槽位

- `initialUnlockedSlotCount` 默认配置为 5，按槽位 ID 从小到大初始化已解锁标记，其余槽位未解锁；编辑器取值范围为整数 `[0, 30]`。
- 初始解锁不采样价格、不扣金钱；后续解锁仍使用目标槽位 ID 采样价格。
- 初始解锁数量在新运行时初始化时生效，快照恢复保留快照记录的解锁标记。

### 槽位解锁价格

- 配置入口：`Data/config.json` 的 `slotUnlockCurve`，编辑器显示名为“槽位解锁曲线”。
- 输入为槽位 ID，合法范围为整数闭区间 `[1, 30]`；直接使用 ID 采样，不作等级或索引偏移。
- 输出为该槽位的解锁价格：向下取整（基础值 + 槽位 ID 的幂值次方 × 倍率）。
- 价格仅在点击槽位后由 Inspector 展示，按 State 中选中的槽位 ID 采样；调整曲线参数后刷新当前价格。
- 解锁操作按执行时的当前价格扣除 `State.money`，并将该槽位的 `unlocked` 设为已解锁；余额不足或已解锁时不结算。
- 当前价格参数仅为实现占位值，尚未确认或校准；后续在曲线编辑器中调整。

### 金钱

- 初始值来自 `Data/config.json` 的 `initialMoney`（编辑器显示“初始金钱”），进入新运行时初始化 `State.money`；当前默认值仅用于实现，尚非已确认的经济目标。
- 解锁后金钱 = 解锁前金钱 − 当前槽位解锁价格；余额必须至少等于价格，不允许重复解锁扣款。
- 快照保存并恢复当前金钱与各槽位的解锁标记，改变初始金钱不直接增加当前余额。

### 矿石刷新与变异

- 配置入口：`Data/config.json` 的“矿石刷新”目录。
- `miningRefreshInterval` 为整批刷新间隔，单位为在线秒数，默认 300，取正整数。
- `miningSpawnCount` 为每批矿石数量，默认 20，取正整数；每次整批替换，不与上一批数量累加。
- `State.miningRefreshElapsedSeconds` 从 0 开始，每个在线 Tick 增加 1；达到当前刷新间隔时生成一批矿石并将计时归零，首批在满 300 秒时生成。`State.miningOres` 保存当前批次矿石及变异结果，两者随快照保存和恢复。
- `miningMutationProbabilityCurve` 使用框架内置的 `lottery` 抽奖概率曲线，分布类型为 `GeometricDecay`，`prizeCount` 为 6，结果 ID 为整数 `[1, 6]`。
- 通过衰减系数 `r` 配置六档概率，合法范围为 `0 < r <= 1`；结果 ID 为 `j` 时，权重为 `r^(j - 1)`，概率由六项权重归一化得到，合计为 1；`r = 1` 时六档等概率。
- 本次保留已有配置 `r = 0.45`，不调整变异分布。每块矿石互斥抽取一个结果，包含普通结果，不是分别独立触发。

| 结果 ID | 结果 | 相对权重 |
| --- | --- | --- |
| 1 | Normal（普通） | 1 |
| 2 | Toxic | r |
| 3 | Frost | r^2 |
| 4 | Inferno | r^3 |
| 5 | Storm | r^4 |
| 6 | Astral | r^5 |

- 自动刷新已接入模拟器 State；数量、间隔与变异概率读取当前 Config，调参不立即修改已刷出的矿石，下次刷新时生效。未修改或导出 Roblox 配置。

### 手动取矿、熔炼与打造

- “手动打造”配置目录中，`oreCollectInterval` 默认 30 在线秒，作为点击“打造”的取矿冷却；`initialPlayerLuck` 默认 1（实现临时值，非已校准成长目标）。
- `miningMutationLuckCurve` 以变异 ID 为输入，合法范围为整数闭区间 `[1, 6]`，当前输出 W = ID，沿用六种矿石对应幸运 1～6；产出须为正整数。原料继承变异，不重新抽取幸运；人物幸运不直接乘到收益上。
- 点击“打造”每次只消耗 1 块最佳变异矿石，得到 1 份原料并完成一轮打造；取矿计时最多累计一个间隔，成功取矿后归零，无矿时不消耗额度、不使用随机数。冷却就绪不会自动取矿。当前不额外模拟取矿、制料或单锤耗时，也不增加打造金币消耗。
- 锻造概率采用外部《锻造设计》的试玩规则，集中在 `Code/Formulas.ts` 的 `calculateForgeProbabilities()`，以下数值均为单锤百分数，不是整轮产出概率。

| 当前品质 | 基础成功 | 不变 | 基础破损 | 消失 |
| --- | --- | --- | --- | --- |
| P−4 | 94 | 5 | 1 | 0 |
| P−3 | 93 | 5 | 2 | 0 |
| P−2 | 91 | 5 | 4 | 0 |
| P−1 | 88 | 5 | 7 | 0 |
| P | 70 | 5 | 22 | 3 |

- 仅冲 +1（当前 Q = P）应用原料幸运修正：幸运差最多计算 10 级；好料每高 1 级将基础成功乘以 `1 + 0.2 × 差值`，最高为 `100 − 不变 − 消失`；坏料乘以 `1 − 0.05 × 差值`。不变、消失不动，破损为剩余概率。
- 品质从 P−4 开始，成功加 1，不变继续且无保底；达到 P+1 后不再敲击，不实现冲 +2～+4。破损保留当前品质，消失无成品；品质允许按完整 P±偏移为负，不擅自截断。
- 成品不自动入槽。玩家选择目标已解锁槽位后放入当前武器；目标已有武器时明确点击“替换”，旧剑直接从 `State.swords` 删除，不再限制新剑品质必须更高。同一武器不能重复放入多个槽位。
- 取矿冷却、人物幸运、成品库存、当前展示武器、槽位武器引用与最近打造结果均保存在 State；手动操作记录为 user Action。离线及空闲不推进矿石刷新和冷却，也不会自动打造或放置。

### 槽位内成品武器升级

- `SwordState.level` 初始为 1，与品质 Q 独立保存；只有已放入已解锁槽位的武器才能点击升级，每次升 1 级。
- `swordUpgradeCurves` 是共用等级输入的曲线组，输入为当前武器等级，合法范围为整数 `[1, +∞)`，未确认等级上限，不设置虚假上限；若之后配置 `input.max`，达到上限时停止升级，不采样越界的下一档。
- `upgradeCost` 为当前等级升一级的金币费用，当前沿用 Roblox 临时规则 `25 × 当前等级`；`levelMultiplier` 为等级倍率，临时为 `0.5 + 0.5 × 等级`，对应原有每级收益 10、15、20… 的相对比例。这些数值不是已校准的经济目标。
- 升级前必须有足够金币，成功后扣当前费用并增加武器等级，品质、变异和幸运不变。Game 显示费用及等级倍率，但本次不接入武器收益结算；初始金币仍为 0，升级体验需配置初始金钱或已有金钱余额，不自动赠送金币。
