## 3. 资源关联配置

`initialMoney`（初始金钱）显示在 Config 最外层；`initialUnlockedSlotCount`（初始解锁槽位数）和 `slotUnlockCurve`（槽位解锁曲线）统一显示在“槽位配置”目录。

### 初始槽位

- `initialUnlockedSlotCount` 默认配置为 5，按槽位 ID 从小到大初始化已解锁标记，其余槽位未解锁；编辑器取值范围为整数 `[0, 30]`。
- 初始解锁不采样价格、不扣金钱；后续解锁仍使用目标槽位 ID 采样价格。
- 初始解锁数量在新运行时初始化时生效，快照恢复保留快照记录的解锁标记。

### 槽位解锁价格

- 配置入口：`Data/config.json` 的 `slotUnlockCurve`，编辑器显示名为“槽位解锁曲线”。
- 输入为槽位 ID，合法范围为整数闭区间 `[1, 30]`；直接使用 ID 采样，不作等级或索引偏移。
- 输出为该槽位的解锁价格：向下取整（基础值 + 槽位 ID 的幂值次方 × 倍率）。
- 价格仅在点击槽位后由 Inspector 展示，按 State 中选中的槽位 ID 采样；调整曲线参数后刷新当前价格。
- 解锁操作按执行时的当前价格扣除 `State.money`，并将该槽位的 `unlocked` 设为已解锁；余额不足或已解锁时不结算。
- 当前价格参数仅为实现占位值，尚未确认或校准；后续在曲线编辑器中调整。

### 金钱

- 初始值来自 `Data/config.json` 的 `initialMoney`（编辑器显示“初始金钱”），进入新运行时初始化 `State.money`；当前默认值仅用于实现，尚非已确认的经济目标。
- 解锁后金钱 = 解锁前金钱 − 当前槽位解锁价格；余额必须至少等于价格，不允许重复解锁扣款。
- 快照保存并恢复当前金钱与各槽位的解锁标记，改变初始金钱不直接增加当前余额。
